# src

A Python package skeleton made by `uv init`, together with `../main.py`
and `../pyproject.toml` at the repository root.

| File | Purpose |
|---|---|
| `plain_text_workout/__init__.py` | A placeholder `main()` that prints a greeting. `pyproject.toml` names it as the `plain-text-workout` script. |

Nothing uses it yet. The parser, the servers and the web app are in
`../workout_syntax/` (Rust) and `../app/` (JavaScript).
